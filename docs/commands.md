# Commands

Everything in Spiritbound can be set in the options window (`/spirit`). These chat commands are shortcuts.

`/spiritbound` works everywhere `/spirit` does. Commands only do something on a priest.

## Windows and help

| Command | What it does |
| --- | --- |
| `/spirit` | Opens or closes the options window. `/spirit options` and `/spirit config` do the same. |
| `/spirit help` | Lists every command in chat. |
| `/spirit assign` | Lists who buffs the group with each Prayer. `/spirit assign 1` takes or releases the first one. See [Buff key](features/buff-key.html#sharing-the-buffs-with-other-priests). |

## Frames

| Command | What it does |
| --- | --- |
| `/spirit unlock` | Unlocks all frames so you can drag and resize them. See [Frames and minimap](features/frames-and-minimap.html). |
| `/spirit lock` | Locks the frames again. |
| `/spirit move` | Unlocks the frames, or locks them if they are unlocked. |
| `/spirit reset` | Puts every frame back in its default place and size. |
| `/spirit grid` | Turns snapping to the grid on or off. |
| `/spirit grid 30` | Sets the grid size (4 to 100) and turns snapping on. |
| `/spirit minimap` | Shows or hides the minimap button. |

## Tooltips

| Command | What it does |
| --- | --- |
| `/spirit explain` | Turns the [explanations](features/explanations.html) in tooltips on or off. |

Each command also works without the space, for example `/spiritunlock` or `/spiritreset`. That helps with chat setups that swallow the Enter key after a space.

Type anything else after `/spirit` to get the list of commands in chat.

The [buff key](features/buff-key.html) is not a command: set it on the **Extras** page of `/spirit`.
